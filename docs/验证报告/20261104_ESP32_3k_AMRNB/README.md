# ESP32 3k 与 AMR-NB 测评资料入口

两个 Codec 均在 ESP32-S3 运行，PC 仅控制、导出、重采样和评分。采用已保存的真实测量，不在本次目录整理中补造测量值。

- [主对比报告](esp32_metrics_comparison_20261104_035832/二者量化对比.md)
- [测评口径](esp32_metrics_comparison_20261104_035832/测评口径.md)
- [主要指标 CSV](esp32_metrics_comparison_20261104_035832/主要指标对比.csv)
- [3k 优势与差距](esp32_3k_advantages_20261104/3k优势与差距补充说明.md)
- [宽带同参考逐段指标](esp32_3k_advantages_20261104/宽带同参考评分.csv)

结论：3k 相比 MR475 的纯语音码率节省 36.84%，原生 16 kHz；现有少量样本里有局部宽带与信噪比优势，但平均窄带 PESQ、STOI 及 ESP32 解码速度落后。固定 3 秒解码均值 8470 ms 对 152.577 ms。不能据此推断无线全链路速度，因为 AMR 未测 LoRa/扬声器链路。

三个质量样本数量少，部分固定语音相关，不能证明跨说话人、跨场景的普遍优势。真人 2 秒 STOI 差约 0.0020 也不是统计等效证据。失败轮次不从逐轮表移除。

本目录公开副本仅将本机根路径替换为 `${PROJECT_ROOT}`、`${BUILD_HOME}`；数值、原始固件哈希和失败记录保留。机器专属路径不是构建要求。顶层指标 JSON 中引用的原始文件哈希属于原始数据，不能用于校验脱敏后的报告文本。

原始 PCM、WAV、串口日志、固件、AMR 来源文件及分析依赖位于本地忽略目录 `deliverables/esp32_metrics_comparison_20261104_035832/` 和 `deliverables/esp32_3k_advantages_20261104/`。公开目录没有重复这些附件；原始 `SHA256SUMS.txt` 仍保存在附件数据集中。

复算入口及依赖见 [host/benchmarks](../../../host/benchmarks/README.md)。这些是历史测评；本次 UI 固件验证边界另见 [当前版本说明](../../AiBox当前版本与限制_20261104.md)。
