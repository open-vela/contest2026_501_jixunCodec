# 1k / 3k / 6k 双板 50 轮稳定性测试

测试时间：2026-09-20
测试入口：`_rate_cycle_50.py`
测试命令：`jixun bench 1`，固定 1 秒输入，关闭 `JX_USB`、`JX_PCM_DUMP`、`JX_BEEP`

## 测试范围

- 对每个码率分别给 COM4、COM23 写入同一应用区镜像，只写 `0x10000`。
- 每块板连续运行 50 轮 `jixun bench 1`，以 NSH 提示符作为轮次边界。
- 共 300 轮原始日志，逐轮记录编码耗时、解码耗时、总耗时和输出指纹。
- 本轮验证 codec 核心的确定性、数值一致性和热稳定抖动，不包含 Wi-Fi、UDP/TCP、PC 中转或扬声器播放链路。

## 结论

- 三个码率、两块板、共 300 轮全部成功，没有断言、超时或无响应。
- 同一码率下，每块板的 50 轮指纹完全相同；COM4 和 COM23 的输出指纹也一致。
- 热稳定阶段 CV 为 `0.157%-0.487%`，一致性很好。首轮冷启动固定比热稳定慢约 `110-130 ms`，是每块板唯一明显的慢点。
- 6k 的总耗时标准差约 `18-22 ms`，比 1k/3k 的约 `6-7 ms` 高，主要因为 token 数和计算量更大，但相对抖动仍低于 `0.5%`。
- 3k 热稳定总耗时约 `3.31 s`，低于本轮记录的冷启动 `3.43-3.44 s`。
